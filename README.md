# членсосейлс — Telegram Mini App

Никакой сборки APK, никакого Appflow, никакого Android SDK. Просто веб-страница,
которую Telegram открывает внутри себя. Всё делается с телефона через Chrome.

## Шаг 1. Загрузить файлы на GitHub (без папок!)

Все 5 файлов кладём прямо в корень репозитория — без вложенных папок,
так что «создавать папку» вообще не понадобится.

1. Удали старый zip-файл из репозитория, если он там есть (тапни на файл → значок корзины → Commit).
2. На главной странице репозитория: **Add file → Upload files**.
3. Выбери из скачанного архива 5 файлов: `index.html`, `style.css`, `config.js`, `api.js`, `app.js`
   (без всякой папки www — прямо эти пять файлов).
4. Внизу — **Commit changes**.

В итоге в корне репозитория должно лежать ровно 5 файлов, без папок и без zip.

## Шаг 2. Включить GitHub Pages (бесплатный хостинг)

1. В репозитории: **Settings** (шестерёнка) → в левом меню **Pages**.
2. В разделе **Build and deployment** → **Source**: выбери **Deploy from a branch**.
3. **Branch**: выбери `main`, папка — **/ (root)**.
4. Нажми **Save**.
5. Подожди 1-2 минуты, обнови страницу — вверху появится зелёная плашка со ссылкой вида:
   `https://твой-логин.github.io/название-репозитория/`

Это и есть публичный HTTPS-адрес твоего приложения. Открой его в браузере, чтобы
убедиться, что страница поиска билетов реально загружается.

## Шаг 3. Вставить токен Travelpayouts

Если ещё не вставил — открой `config.js` прямо на GitHub (тапни на файл → карандаш ✎
для редактирования), замени `"ВСТАВЬ_СВОЙ_ТОКЕН_СЮДА"` на свой токен, Commit changes.
Подожди минуту-две, пока GitHub Pages обновит страницу.

## Шаг 4. Создать Telegram-бота и подключить Mini App

1. В Telegram открой **@BotFather**.
2. Отправь `/newbot`, придумай имя и username бота (username должен заканчиваться на `bot`).
3. BotFather пришлёт токен бота — он не понадобится для Mini App, просто сохрани на всякий случай.
4. Отправь BotFather команду `/newapp`.
5. Выбери своего бота из списка.
6. Введи название приложения (например, «членсосейлс»).
7. Пришли короткое описание (пара слов).
8. Пришли фото/иконку 640×360 (можно любую картинку, она нужна для карточки приложения).
9. Когда попросит **Web App URL** — вставь ссылку с GitHub Pages из Шага 2.
10. Готово — BotFather пришлёт ссылку вида `t.me/твой_бот/app_name`.

## Шаг 5. Открыть приложение

Просто перейди по ссылке `t.me/твой_бот/app_name` или открой бота и нажми на кнопку
меню (значок ≡ или синяя кнопка снизу) — приложение откроется прямо внутри Telegram,
на весь экран, без установки APK.

## Если что-то не грузится

- Белый экран в Telegram → открой ту же ссылку GitHub Pages в обычном браузере
  (Chrome) — если и там белый экран, проблема в самих файлах (пришли скрин ошибки
  из консоли браузера, если получится её открыть).
- Ошибка при поиске билетов → проверь, что токен в `config.js` вставлен без лишних
  кавычек и пробелов.
- Страница на GitHub Pages не открывается / 404 → подожди пару минут, Pages
  обновляется не мгновенно, или проверь, что во вкладке Settings → Pages статус
  «Your site is live».

## Важно про API-токен на публичной странице

GitHub Pages — публичный хостинг, и `config.js` с твоим токеном будет виден любому,
кто откроет страницу и посмотрит исходный код. Для пет-проекта для себя/друзей это
обычно не страшно, но не выкладывай ссылку широкой публике и не используй токен,
привязанный к чему-то важному.
